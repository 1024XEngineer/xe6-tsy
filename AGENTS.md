# Project Agent Rules

Read these files before changing product, architecture, code, or documentation:

1. `docs/项目记忆/README.md`
2. `docs/项目记忆/长期记忆.md`
3. `docs/项目记忆/协作规范.md`
4. `docs/项目记忆/XEngineer营规范摘要.md`
5. `docs/每日工作/README.md`
6. Today's file under `docs/每日工作/YYYY-MM-DD.md`, when present
7. `docs/文档入口.md`
8. `docs/决策日志.md`

The accepted project direction takes precedence over proposals. Issue #37 is an
architecture and technology-selection input; its proposed choices do not
override accepted decisions recorded in project memory.

Codex must not create a pull request targeting `main`, merge into `main`, or
push changes directly to `main`. Foundation work is prepared on `dev` unless
the user explicitly changes the target branch in a later instruction.
