# 当前阶段范围

## 1. 阶段目标

做出 Lingow 一条可验证的两语言面对面句级传译链路，证明 SDK/后端能力可以接入硬件载体或演示端。

阶段成功标准：

- 支持用户选择一组双语语言对，默认 `zh-CN <-> en-US`。
- 支持两方轮流说话。
- 首页支持进入对话模式的按钮或语音唤醒。
- 语音唤醒仅在页面已打开且麦克风授权后生效。
- 完成首页、开始传译、语言选择和基础状态展示区域。
- 进入后显示“Lingow 已进入对话模式”。
- 动态展示自动语言识别结果。
- 支持说话人识别。
- 说话时后台实时识别和翻译，但只在句末后播音。
- 支持基础抢话/打断处理。
- 支持语音合成播放。

## 2. 本阶段必须做

### 实时音频

- WebRTC 音频会话接入
- WebRTC audio track 接收
- 说话人识别
- 自动语言识别
- VAD / 句末检测
- ASR partial/final
- 翻译 final
- TTS 播放指令
- 打断事件

### 应用 API

- 会话创建/结束
- WebRTC 信令
- 对话模式状态
- 可选语言列表和语言对配置
- 演示客户端/设备接入
- 状态快照查询
- 健康检查

### Web

- 响应式页面基础结构，兼容桌面端和手机浏览器
- 首页、开始传译、语言选择、基础状态展示区域
- 按钮或语音唤醒进入对话模式
- 语音唤醒仅在页面已打开且麦克风授权后生效
- 显示“Lingow 已进入对话模式”
- 显示“已识别中文/英语”等语言识别状态
- 显示语音识别、翻译和 TTS 播放组件状态
- 预留后续面对面沟通、跨设备会话和多人会议入口
- 不展示字幕文本

### 手机端

- 模拟设备侧采集
- 开始/结束会话
- 语言选择
- 展示 Lingow 对话模式、语言识别、播放状态
- 验收说话人识别和延迟诊断

### 设备 SDK

- 鉴权
- 创建会话
- WebRTC 音频接入
- 接收播放指令
- 上报播放完成/中断
- 重连

## 3. 本阶段不做

- 不做无限制语言市场和复杂语言包管理
- 多人会议同传
- 字幕展示
- 管理后台
- 官网售卖、支付、订单和发票
- 完整离线翻译
- 自研硬件制造
- 个人微信号硬件化
- 复杂 CRM 或销售自动化
- 私有化部署
- 生产级权限体系

## 4. 待确认但不阻塞首期

- 最终硬件音频格式：PCM、Opus 或厂商自定义。
- 是否必须支持蓝牙配网。
- TTS 声音风格是否需要男女声、正式/自然风格。
- “主人/对方”的身份绑定方式：按设备佩戴侧、声纹，还是手动指定。
