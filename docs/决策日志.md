## D-20260715-001：MS1 先建立最小 Gin 基础框架

日期：2026-07-15
状态：accepted
依据：Issue #37、训练营“代码即架构”规范、用户范围确认

选择：在 `dev` 建立 Go + Gin 可启动骨架，提供统一配置、`/api/v1` 分组、七模块
挂载边界、健康检查和最小测试。本次不实现业务功能接口、provider、契约、

业务细节。后续能力由独立 Issue 和小范围 PR 增量实现。

## D-20260715-003：固定桌面前端与仓库目录位置

日期：2026-07-15
状态：accepted
依据：Issue #37、用户要求先规划全部目录

选择：Gin 后端固定在 `apps/api`；Wails 桌面壳固定在 `apps/desktop`；Vue 3 +
TypeScript + Vite 前端固定在 `apps/desktop/frontend`；跨前后端契约固定在
`packages/contracts`；部署和工程脚本分别放在 `deployments` 与 `scripts`。

本次只冻结目录所有权，不安装前端依赖、不创建功能页面、不提前定义业务 API。
