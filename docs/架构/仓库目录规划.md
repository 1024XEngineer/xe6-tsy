## 放置规则

| 内容 | 位置 | 说明 |
|---|---|---|
| Gin 启动、路由、中间件 | `apps/api` | 后端唯一进程入口 |
| 七模块领域状态 | `apps/api/internal/modules` | 模块边界，不拆为七个微服务 |
| Wails 原生能力与打包 | `apps/desktop` | 只负责桌面和设备边界 |
| Vue 页面和交互 | `apps/desktop/frontend` | 薄客户端，不保存权威业务状态 |
| API schema 与生成类型 | `packages/contracts` | 前后端单一契约来源 |
| 数据库 migration | 后续建立 `apps/api/migrations` | 仅在数据库 Issue 接受后创建 |
| 供应商 adapter | 后续建立 `apps/api/internal/providers` | 仅通过后端 port 接入 |
| 部署配置 | `deployments` | 不提交密钥或环境私有值 |
| 一次性工程命令 | `scripts` | 不承载业务逻辑 |

本次只确认目录及所有权，不安装 Wails/Vue、不增加功能页面、不定义业务 API。
