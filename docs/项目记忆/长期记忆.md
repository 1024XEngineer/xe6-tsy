# 长期记忆

更新时间：2026-07-15

## 项目主体

项目是供基层政务窗口工作人员使用的方言沟通辅助 PC Agent，不是会议
软件、群众端 App、自动审批系统或开放式自主 Agent。

主链为：

```text
工作人员访问与机构配置
  -> 接待会话
  -> 方言原文和标准普通话表达
  -> 事项与事实候选
  -> 带来源的政策材料引用
  -> 咨询记录草稿
  -> 最终人工审查与定稿
```

## 稳定架构边界

- PC Agent 是薄客户端；七模块业务状态属于 Go API 模块化单体。
- 七模块是领域和状态所有权边界，不是七个微服务。
- ASR、模型、RAG 和 TTS 只能通过后端 provider port 接入。
- 模型输出只能形成候选或草稿，模块 7 是唯一最终人工审查入口。
- 正式政策引用必须绑定机构、知识发布版本、来源位置和内容哈希。
- 默认不保存原始音频，不使用持久声纹，不处理真实群众数据。

## MS1 Foundation 范围

当前 `dev` 只建立 Issue #37 的最小 Gin 基础框架：服务启动、配置、API 版本分组、
七模块挂载边界、健康检查和测试。暂不实现业务功能接口、数据模型、provider、
契约、数据库、桌面端或真实音频链；这些内容由后续独立 Issue 增量补充。

仓库目录已固定：Gin 后端位于 `apps/api`，Wails 桌面壳位于 `apps/desktop`，
Vue 前端位于 `apps/desktop/frontend`，跨前后端契约位于 `packages/contracts`。
目录位置已接受不代表对应功能已实现。
